프로젝트 개요 (Overview)

주요 목표

  • 기상청(KMA) 공식 API 기반의 정확한 기상 데이터 수집
  • Premium 디자인 시스템 적용 및 자동 HTML 생성
  • 서버 자동 배포 워크플로우를 통한 실시간 정보 업데이트
  • 사용자 기호에 최적화된 시각적 대시보드 제공

1. 데이터 계층

기상청 초단기 실황/예보 API를 비동기 호출하여 기온, 습도, 풍속 등 핵심 기상 지표를 확보합니다.

2. 로직 계층

Lambert 투영법 알고리즘을 통해 GPS 좌표를 기상청 전용 격자 좌표(NX, NY)로 정밀 변환합니다.

코드 구조 (Code Structure)

Data Acquisition

httpx를 이용한 비동기 API 통신 및 타임 아웃 제어

fetch_weather_data()

Rendering Engine

Jinja2 템플릿 엔진을 활용한 동적 HTML 시각화

generate_html()

Auto Deployment

Paramiko SSH 및 SCPClient를 통한 서버 전송 및 URL 생성

deploy_to_server()
