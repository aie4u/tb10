🔴 긴급 — 즉시 수정 필요

1. 아이콘에 접근 가능한 이름 없음

WCAG 1.1.1

Lucide 아이콘이 <i> 태그로 렌더링되나, 대체 텍스트나 aria-label이 없어 스크린 리더 사용자가 내용을 인식할 수 없습니다.

- <i data-lucide="cloud-sun" class="w-6 h-6"></i>
+ <i data-lucide="cloud-sun" class="w-6 h-6" aria-hidden="true"></i>

영향 범위: 8개 이상의 아이콘 요소

2. 색상 대비 부족

WCAG 1.4.3

헤더 영역의 opacity-70 설정으로 텍스트 대비 비율이 약 2.8:1로 최소 요구치(4.5:1)에 미달합니다.

- <div class="... opacity-70">
+ <div class="... opacity-90">
- class="text-sm text-gray-600"
+ class="text-sm text-gray-700"

3. 시맨틱 랜드마크 구조 부재

WCAG 1.3.1

<main> 랜드마크가 없고, <section> 태그에 aria-labelledby가 누락되어 보조 기술 사용자가 페이지 구조를 파악할 수 없습니다.

+ <main id="main-content" tabindex="-1">
+ <section aria-labelledby="overview-heading">
+ <h2 id="overview-heading">...</h2>

4. 포커스 표시기 미정의

WCAG 2.4.7

포커스 스타일이 전혀 정의되어 있지 않아 키보드 사용자가 현재 위치를 파악할 수 없습니다.

+ :focus-visible {
+ outline: 3px solid #064789;
+ outline-offset: 2px;
+ }

5. 스킵 내비게이션 링크 없음

WCAG 2.4.1

페이지 상단에 "본문으로 건너뛰기" 링크가 없어 키보드 사용자가 매번 전체 헤더를 탐색해야 합니다.

+ <a href="#main-content" class="skip-link">본문으로 건너뛰기</a>

🟡 중요 — 출시 전 수정

6. 제목(heading) 레벨 구조 불완전

WCAG 1.3.1

<h4>가 <h2> 바로 아래에 사용되어 제목 레벨이 순차적이지 않습니다. <h3>으로 변경이 필요합니다.

위치 수정 전 수정 후
데이터 계층 <h4> <h3>
로직 계층 <h4> <h3>
Data Acquisition <h4> <h3>
Rendering Engine <h4> <h3>
Auto Deployment <h4> <h3>

7. 색상만으로 정보 전달

WCAG 1.4.1

색상 견본 영역의 색상 블록이 색상에만 의존하여 정보를 전달합니다. 색각 이상자를 위해 role="img" 및 aria-label로 색상명 라벨을 추가합니다.

8. 모션 축소(prefers-reduced-motion) 미지원

WCAG 2.3.3

모션 민감 사용자를 위한 @media (prefers-reduced-motion) 쿼리가 누락되었습니다.

+ @media (prefers-reduced-motion: reduce) {
+ *, *::before, *::after {
+ animation-duration: 0.01ms !important;
+ transition-duration: 0.01ms !important;
+ }
+ }

9. Mermaid 다이어그램 접근성

WCAG 1.1.1

Mermaid 다이어그램에 대체 텍스트가 없어 스크린 리더 사용자가 내용을 이해할 수 없습니다.

+ <div class="mermaid" role="img"
+ aria-label="시스템 데이터 흐름: KMA API → Python → Jinja2 → HTML → Server">

🟢 보통 — 가능한 빨리 수정

10. Footer 랜드마크

접근성

<footer>에 role="contentinfo" 속성을 추가합니다.

11. 오탈자 수정

품질

"Steel Aznure" → "Steel Azure"로 2곳 수정합니다.

12. CDN 의존성

안정성

Tailwind, Lucide, Mermaid 3개 CDN 장애 시 대응이 필요합니다.
